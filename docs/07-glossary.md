# 07 — Glossary

Game terms in alphabetical order.

| Term | Definition |
|---|---|
| **Action queue** | The ordered list of actions chosen by the active player before pressing READY. |
| **Affliction** | Umbrella for negative statuses (poison, bleed, drained, ...). |
| **AOE** | Area of effect — a skill hitting all enemies (or all allies). |
| **Archetype** | A character's functional category (damage dealer, healer, tank, ...). |
| **Bleed** | DoT whose damage scales with damage dealt by the source character. |
| **Blessing** | Umbrella for positive statuses (regen, damage reduction, invulnerable, ...). |
| **Control** | Ongoing skill that breaks if the user↔target link is severed. |
| **Cooldown** | Number of turns a skill is unusable after being cast. |
| **Copy** | Modifier: the user temporarily gains a copy of a skill from the target. |
| **Destructible shield** | A pool of HP that absorbs damage until depleted. |
| **Disarm** | Status: the character cannot use physical skills. |
| **Dodge** | The universal defense skill: invulnerable for 1 turn, cost 1 generic, cooldown 4. |
| **DoT** | Damage over Time — damage applied each turn for X turns. |
| **Drained** | Status: the team loses 1 random essence at turn start. |
| **Elo** | Ranked rating; goes up on wins, down on losses. |
| **Essence** | Resource for casting skills. Four colors (Vigor, Spirit, Mind, Blood) + Generic. |
| **Generic** | Cost slot accepting any color of essence. |
| **HoT** | Heal over Time — healing applied each turn for X turns. |
| **Inevitable** | Modifier: ignores dodge and reflect. |
| **Instant** | Skill resolving immediately on its turn, no follow-up effect. |
| **Invulnerable** | Status: immune to direct enemy skills. |
| **Marked** | Status: takes extra damage from specific sources. |
| **MMR** | Match-Making Rating — a hidden synonym for Elo. |
| **Piercing** | Modifier: ignores damage reduction and destructible shield. |
| **Reflect** | Bounces a skill back to its caster. |
| **Reflective** | Status: the next enemy skill is reflected. |
| **Regen** | Synonym for HoT. |
| **Silence** | Status: the character cannot use magical skills. |
| **Stealth** | Status: the character cannot be targeted until they attack. |
| **Stun** | Status: the character cannot act this turn. |
| **True** | Modifier: ignores invulnerability. |
| **Vulnerable** | Status: cannot gain invulnerability or damage reduction. |
