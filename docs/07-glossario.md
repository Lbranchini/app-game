# 07 — Glossário

Termos do jogo, em ordem alfabética.

| Termo | Definição |
|---|---|
| **Ação contínua** | Habilidade que dura múltiplos turnos. Pausa se o usuário for atordoado; retoma depois. |
| **Aflição** | Categoria geral de status negativos (veneno, sangramento, drenado, etc.). |
| **AOE** | Area of Effect — habilidade que atinge todos os inimigos (ou todos os aliados). |
| **Arquétipo** | Categoria funcional do personagem (damage dealer, healer, tank, controle...). |
| **Atordoado** | Status que impede o personagem de usar qualquer habilidade no turno. |
| **Bênção** | Categoria geral de status positivos (regeneração, redução de dano, invulnerável). |
| **Cooldown** | Quantos turnos uma habilidade fica indisponível depois de usada. |
| **Controle** | Tipo de habilidade contínua que **quebra** se o vínculo usuário↔alvo é rompido. |
| **Cópia** | Modificador: usuário ganha temporariamente uma cópia de habilidade do alvo. |
| **Defesa destrutível** | Escudo de HP que absorve dano até ser quebrado. |
| **Desarmado** | Status: não pode usar habilidades físicas. |
| **DoT** | Damage over Time — dano aplicado todo turno por X turnos. |
| **Drenado** | Status: time perde 1 essência aleatória no início do turno. |
| **Elo** | Pontuação de ranking. Sobe ao vencer, desce ao perder. |
| **Esquiva** | Habilidade universal: invulnerável por 1 turno, custo 1 essência genérica, cooldown 4. |
| **Essência** | Recurso para usar habilidades. 4 tipos: Vigor, Espírito, Mente, Sangue. |
| **Furtivo** | Status: inimigos não podem alvejar até o personagem atacar. |
| **Genérica** | Custo de essência que aceita qualquer cor. |
| **HoT** | Heal over Time — cura aplicada todo turno por X turnos. |
| **Inevitável** | Modificador: ignora esquivas e reflexões. |
| **Instantânea** | Habilidade que resolve no turno e não tem efeito posterior. |
| **Invulnerável** | Status: imune a habilidades inimigas direcionadas. |
| **Marcado** | Status: sofre dano extra de fontes específicas. |
| **MMR** | Match-Making Rating, sinônimo de Elo escondido. |
| **Perfurante** | Modificador: ignora redução de dano e defesa destrutível. |
| **Redução de dano** | Status: subtrai X de cada acerto recebido. |
| **Reflect** | Devolve a habilidade ao lançador. |
| **Refletivo** | Status: próxima habilidade inimiga é refletida. |
| **Regeneração** | Sinônimo de HoT. |
| **Sangramento** | Status DoT: dano proporcional ao dano causado pelo personagem. |
| **Silenciado** | Status: não pode usar habilidades mágicas. |
| **Stun** | Sinônimo de atordoado. |
| **Verdadeiro** | Modificador: ignora invulnerabilidade. |
| **Veneno** | Status DoT: X dano por turno, fixo. |
| **Vulnerável** | Status: não pode receber invulnerabilidade ou redução de dano. |
